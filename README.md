# 🛡️ BPLA Analytics: Интерактивная аналитика и статистика оповещений о БПЛА

[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)
[![Демо](https://img.shields.io/badge/🌐_Открыть_интерактивный_отчет-10a37f)](https://YOUR_USERNAME.github.io/BPLA_statistics/)

> **Открытый инструмент для аналитики воздушной обстановки.** В отличие от карт реального времени, этот проект предоставляет **глубокую статистическую аналитику**, выявление трендов и прогнозирование активности беспилотных летательных аппаратов (БПЛА) на основе открытых данных Telegram-каналов.

## 🎯 Что умеет этот инструмент?
Если вы искали *аналитику атак дронов*, *статистику оповещений РСЧС* или *прогноз активности БПЛА*, этот репозиторий закрывает эту потребность:
- 📊 **Интерактивный дашборд** с детализацией по часам, дням недели и локациям.
- 📈 **Многоуровневый анализ трендов** (неделя/месяц/квартал) с удалением информационных шумов и прогнозом.
- 🕯️ **Свечные графики** активности, адаптированные для оценки угроз.
- 🤖 **Автоматическая генерация выводов** и рекомендаций для населения на основе данных.

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Экспорт данных из Telegram

1. Откройте Telegram Desktop
2. Перейдите в канал радара (например, «Радар Ставропольского края»)
3. **Настройки → Экспорт истории чата → JSON**
4. Сохраните файл как `messages.json`

### 3. Генерация отчёта

```bash
python drone_report.py messages.json
```

Откроется файл `messages_report.html` — полностью автономный интерактивный отчёт.

### 4. Анализ трендов (опционально)

```bash
python multi_scale_trend.py messages.json
```

Создаст `multi_scale_trend.png` с прогнозом на 3/6/12 месяцев вперёд.

### Автоматические рекомендации

> 🕒 **Пик опасности:** Максимум оповещений приходится на 1:00–2:00. В это время категорически не рекомендуется находиться на открытых пространствах.
> 
> ✅ **Безопасное окно:** Наименьшая активность зафиксирована с 6:00 до 20:00. Это лучшее время для плановых дел на улице.
> 
> 🌙 **Ночной фактор:** 42% всех угроз приходится на ночное время (22:00–06:00). Закрывайте шторы и выключайте свет в тёмное время суток.

##  Как это работает

### Классификация событий

Скрипт автоматически разбивает сообщения на категории:

| Категория | Ключевые слова | Уровень угрозы |
|-----------|---------------|---------------|
| Сбит БПЛА | сбит, уничтож | 9/10 |
| Тревога | тревога | 8/10 |
| Внимание/Опасность | опасность, внимание | 7/10 |
| Угроза масс.запуска | массовый запуск, готовит | 8/10 |
| Фиксация/Пролет | фиксаций, пролет | 6/10 |
| Отбой | отбой | 1/10 |
| *info (10 подкатегорий)* | тихо, монитор, ожид... | 0–8/10 |

### Расчёт трендов

Используется **линейная регрессия с удалением выбросов** (метод IQR). Мощные единичные всплески (например, 93 оповещения за неделю) не искажают общую картину.

**Прогноз** строится на основе наклона тренда и экстраполируется на 3/6/12 месяцев вперёд.

### Анализ сессий

Сессия = период от первого «Внимание/Опасность» до следующего «Отбой». Алгоритм учитывает:
- Сессии в пределах одних суток
- Переход через полночь (до 12 часов)
- Сброс при отсутствии отбоя более 12 часов
